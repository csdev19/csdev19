## 🛠️ Things I’m building

### 🎥 [Kaipu Record](https://kaipu.app)

A desktop screen recorder that saves recordings as regular files in a folder you choose. Screen, system audio, microphone, and camera capture—with a local-first approach.

### 💬 [Yui](https://askyui.app)

A desktop assistant for live conversations. It transcribes on your Mac, keeps the session’s context, and answers when you ask. You can run answers locally or use your own AI provider key.

### ⚡ [Laqi](https://github.com/csdev19/laqi)

A mock API server for building and testing frontends without waiting for a backend. Define responses, switch scenarios from a web panel, and let coding agents control mocks through MCP.
